# Support

Use GitHub Issues for reproducible bugs, documentation corrections, and
feature proposals that fit the project's boundary.

Before opening an issue:

- Read the README and CONTRIBUTING guide.
- Search existing issues.
- Include the package version, Node.js version, operating system, exact
  command or MCP client configuration, and a minimal reproduction.
- Remove credentials and other sensitive data from logs.

This project supports a local, read-only MCP server using stdio and a
checked-in index of official Tauri 2 documentation. It does not provide
support for hosted HTTP transports, arbitrary URL crawling, Tauri runtime
control, authentication, telemetry, or custom private corpora.

Security vulnerabilities must be reported privately as described in
[SECURITY.md](SECURITY.md), not in a public issue.
