# Security Policy

## Supported versions

Security fixes are provided for the latest published version on npm and the
latest commit on `main`. Older versions may not receive fixes.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Report it privately
through [GitHub's private vulnerability reporting](https://github.com/fxckcode/tauri-docs-mcp/security/advisories/new).

Include the affected version or commit, reproduction steps, impact, and any
suggested mitigation. You will receive an acknowledgement as soon as
practical; please allow time for investigation and coordinated disclosure.

This project is intentionally read-only, stdio-only, and constrained to its
checked-in official Tauri documentation corpus. Reports about unsupported
network crawling, hosted HTTP deployment, authentication, or telemetry are
outside this project's security boundary unless they demonstrate a concrete
impact in the supported package.
